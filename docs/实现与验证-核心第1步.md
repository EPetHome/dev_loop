## 命令

完整参数和配置示例见根目录 `README.md`。最短用法：

```sh
bin/loop 启动 <单任务卡.json> --json
# 在任务 worktree 里：
bin/loop 交付 --说明 '实现与自测说明' --json
bin/loop 查询 --all --brief --json
bin/loop 续跑 <执行编号或卡路径> --json
bin/loop 停止 <执行编号或卡路径> --json
bin/loop 放弃 <执行编号或卡路径> --json
```

- `LOOP_TASKS_ROOT` 覆盖 `~/.dev-loop/tasks`；每个测试都使用自己的临时根目录。
- `LOOP_TASK_DIR` 优先定位开发任务，否则按真实 cwd 匹配 worktree；已处理 macOS `/var` 与 `/private/var` 的别名。
- 启动回执先返回，worktree/localFiles/setup/开会话在后台。`LOOP_LAUNCH_CMD` 是测试用可执行替身，自动测试没有开真实窗口。
- 状态协议 `loop-status/1`，五种 state；支持完整简要列表；错误含六类之一及原文。
- 已有通过只按 commit、提示词哈希、验收标准哈希沿用，证据是否存在不影响。
